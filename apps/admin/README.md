# @zerocraft/admin

Next.js 16 admin application for Maara Merch.

Phase 1 contains the application foundation only: design tokens, theme provider,
owned UI primitives, the money module and the foundation status page. See the
repository root `README.md` and `docs/development/implementation-plan.md` for
the real status.

```powershell
pnpm dev
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

Run these from the repository root so the workspace scripts apply.
